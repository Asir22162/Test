# Frontend Template (Vue 3 + Vite 7)

Quick start:

- Install dependencies:

  pnpm -C packages/frontend-template install

- Run dev server (Node 20 recommended):

  pnpm -C packages/frontend-template dev

This template is intended as a minimal starting point for the monorepo's frontend projects and is aligned to the project's version baseline: Vue 3.x and Vite 6/7.
